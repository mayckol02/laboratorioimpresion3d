# laboratorioimpresion3d
laboratorio de impresión 3D
el modelo es una secuencia de letras formando la palabra MAYCKOLL, con una altura de 7mm
el software en el que se realizo el modelo fue en FreeCAD

parametros de impreción sugeridos:
- Altura mínima de letra Más de 8 mm
- Altura de capa (Layer height): 
    0.16 mm → alta calidad (mejor para letras pequeñas o detalles finos).
    0.2 mm → buena calidad general.
    0.28 mm o más → rápida, pero pierde definición en curvas o letras.
- Ancho de línea (Line width): Usa el ancho por defecto de tu boquilla
- Altura de extrusión / grosor total del texto:
    al menos 0.8 mm de profundidad.
- Relleno (Infill): 10–20 % basta, porque lo importante es la superficie.
- Paredes y capas superiores:
    Paredes (perímetros): 3 → da mejor definición al borde de las letras.
    Capas superiores/inferiores: 5 → evita huecos en zonas planas.
- Temperatura y velocidad:
  Depende del material, pero para PLA (más usado para esto):
    | Parámetro               | Valor recomendado                      |
    | ----------------------- | -------------------------------------- |
    | Temperatura de extrusor | 200 °C ± 5 °C                          |
    | Temperatura cama        | 60 °C                                  |
    | Velocidad de impresión  | 40–50 mm/s (más lento = más precisión) |
    | Ventilador              | 100 % después de la primera capa       |
- Adhesión y orientación:
    colócalas acostadas (de lado) para evitar que se caigan.
    usa brim o raft para evitar que se despeguen.
